# 開發方向與移植紀錄

## 目前版本

可離線執行的 Canvas 等角視角網頁遊戲 MVP。這個版本為玩法與開場體驗的基準，並非真正的 3D 遊戲。

- `engine.js`：狀態、資源收支、建造、人力、事件、序章與勝敗規則。
- `game.js`：網頁介面、操作、教學、敘事回饋與瀏覽器存檔。
- `art.js`：原創程序繪圖與居民工作動畫。
- `camera.js`：目前的等角座標與地圖縮放、拖曳計算。
- `tests/`：核心規則、序章與相機的回歸測試。

## 後續評估：Godot 3D 小型原型

引擎方向尚未實作或安裝依賴。先保留可玩的網頁版，再用獨立目錄驗證下列場景：

1. 一張小地形、住宅、集光陣列與居民。
2. 可旋轉、縮放與拖曳的 3D 攝影機，以及手機建造操作。
3. 第一夜恢復供電，住宅逐一亮燈。
4. 在實體手機檢查載入時間、畫面流暢度與操作。

驗證完成後，才決定是否移植全部玩法。網頁版不因這份規劃而停止維護。

## 可保留與需重做的部分

- 保留規則、平衡數值、事件文字、建築識別碼與測試情境。
- 將建築和事件資料由程式整理為可共享的資料格式，定義存檔版本與轉換方式。
- 若採 Godot 原生多平台路線，移植經營規則到 GDScript，並以既有情境比較每日結算結果。
- 重新實作 3D 模型、燈光、角色動畫、攝影機與引擎介面。Canvas 圖形作為外觀參考。
- 居民目前不是完整尋路與人際關係模擬；這些是後續獨立工作。
